One row = one record·One column = one variable

2. Bad Structure

Avoid this layout — it might look fine for a report, but it is not always the best structure for analytics:

JanuaryFebruaryMarch
Sales100001500012000
Profit200030002400

Months are spread across columns — the same variable (Month) lives in three headers.

MonthMetricValue

A cleaner analytical structure: one row per (Month, Metric) observation. Later, this understanding will help you with SQL, pandas, and Power BI.

3. Golden Rule

Golden ruleKeep raw data separate from presentation. Don't mix everything into one chaotic sheet.

Step 2 — COUNT, COUNTA, COUNTIF

These functions look similar but behave differently. Click each formula to highlight the cells it actually counts.

COUNTCounts numeric cells.
=COUNT(A2:A100)
COUNTACounts non-empty cells.
=COUNTA(A2:A100)
COUNTIFCounts cells satisfying a condition.
=COUNTIF(B2:B100,"AI&DS")
Meaning: count how many rows contain AI&DS.

ANDBoth conditions must be true.

Meaning: marks are at least 50 AND attendance is at least 75%.
ORAt least one condition must be true.
=OR(B2>=90,C2>=90)

Step 1 — Why Power Query?

🎯 Learning objectives — you'll understand:
  • why repetitive manual cleaning is inefficient
  • what Power Query does
  • how repeatable transformation works

Microsoft describes Power Query as a data connectivity and transformation technology used across products including Excel and Power BI.

1. The Problem

Imagine receiving this every month:

📄 January.xlsx📄 February.xlsx📄 March.xlsx📄 April.xlsx

Every month you manually: remove columns · clean names · fix dates · remove duplicates · change data types. That is repetitive.

Power Query allows you to record transformation steps. Then you can refresh the process when new data arrives.
